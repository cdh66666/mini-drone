### 怎么打开 KiCad 工程

1. 整个 zip **完整解压**（不要只挑 `.kicad_pcb` 出来，它会找不到符号/封装/3D 模型）；
2. 打开 `01_历史工程_v5_非实板确认版/KiCad/ESP32-1S-Basic-R4-E07-Layout.kicad_pro`；
3. 需要 **KiCad 10.0.7 或更新的版本**（用 9.x 打开会提示工程版本过新）。

包里同时附了原整理方写的 `00_先读_版本与缺失.txt`、`README-先读-审阅范围.txt` 和
`SHA256SUMS.txt`，**建议先看那两个 txt**。

### ⚠️ 版本警告（重要）

包里的可编辑工程是 **2026-10-31 的 E08 v5 历史审阅版**，**不是**你手上这块板的最终版：

- 之后在嘉立创 EDA 里还做过板框圆角、原理图警告整理、MEC 关联修正，这些**没有**包含在里面；
- 里面的 Gerber 是**历史审阅文件，不要拿它再下一次单**；
- 贴装坐标只对那个历史版本有效，**不要直接套到实板**。

**判断依据永远是：实际制板订单的文件 + 实板丝印 + 实测。**
本目录的 PDF 是 11-08 从嘉立创导出的当前版视图，看接线以 PDF 为准，改板以云端工程为准。

### 测试点（USB 焊盘坏了也能救）

| 测试点 | 网络 | 用途 |
| --- | --- | --- |
| TP1 | `EN` | 拉低 = 复位 |
| TP2 | `BOOT` | 上电时拉低 = 进下载模式 |
| TP3 | `UART_TX` | 备用串口（接 USB-TTL） |
| TP4 | `UART_RX` | 备用串口 |
| TP5 | `3V3` | 量 3.3 V |
| TP6 | `GND` | 地 |

> 板子方位：**USB 口那一侧是机尾**，M1/M2 在机头。M1 ↔ M4 对角、M2 ↔ M3 对角。

## 三、关键器件（BOM 核对过）

| 位号 | 型号 | 作用 | 备注 |
| --- | --- | --- | --- |
| U1 | **ESP32-S3-WROOM-1-N8R2** | 主控 | 8 MB Flash + 2 MB PSRAM，实测吻合 |
| U2 | **TPS63020DSJR** | 升降压 DC-DC → 3V3 | 1S 电池 3.0–4.2 V 全程稳 3.3 V |
| U3 | **QMI8658A** | 六轴 IMU | I2C `0x6B`，LGA-14 |
| U4 | **BQ24073RGTR** | 线性充电管理 | USB 插入充电 + 系统供电，实测 189 mA |
| Q1–Q4 | **CJ3400**（SOT-23 NMOS） | 四路电机低边开关 | 栅极 330R 串阻 + 100k 下拉 |
| D1–D4 | **SS34**（SMA 肖特基） | 电机续流 | 关断时给电机电流留回路 |
| L1 | 1.5 µH（MWSA0518S-1R5MT） | TPS63020 电感 | |
| J1 | KH-TYPE-C-16P | USB-C 口 | 16 pin，含 CC 电阻 5.1k |
| J2 | 电池焊盘 | 1S 电池输入 | |
| JM1–JM4 | 电机焊盘 | 四路电机输出 | 每路 2 pin：VBAT + 漏极 |

**驱动器拓扑（决定了固件的限制）**：

```
VBAT ── 电机 ── JMx ── Qx(CJ3400, 低边 NMOS) ── GND
```

低边斩波、**只能单向导通**：固件没法反转转向，换向只能对调电机两根线
（详见上级 `README.md` 第 3.4 节）。四轴本来就只需要一个方向，靠正反桨抵消反扭。
